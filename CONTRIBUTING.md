# Contributing

1. Fork the repository and create a focused branch.
2. Never commit API keys, `.env` files, uploaded data, or model weights.
3. Run `pytest`, `npm run build` in `demo/chat_v2/frontend`, and `docker compose config --quiet`.
4. Describe behavior changes, verification, and upstream compatibility in the pull request.

Contributions derived from DeepAnalyze must retain the MIT license and upstream attribution.
